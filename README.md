# 🚗 停车场倒车挑战

一个纯 HTML/CSS/JavaScript 实现的停车场倒车模拟小游戏，**单文件、零依赖**，双击即玩。

## 🌐 在线试玩

**<https://hydonk3.github.io/parking-game/>**

手机、电脑浏览器均可直接打开，无需安装任何东西。

## 运行方式

直接用浏览器打开 `index.html` 即可（推荐 Chrome / Edge）。

也可以在项目目录启动一个本地服务器：

```bash
# 任选其一
npx serve .
python -m http.server 8080
```

## 操作方式（键盘）

| 按键 | 功能 |
| --- | --- |
| `↑` 方向键 | 前进 |
| `↓` 方向键 | 倒车（会触发倒车雷达提示音） |
| `←` `→` 方向键 | 转向（倒车时方向自动反向，符合真实驾驶） |
| `R` | 重玩当前关卡 |
| `P` / `Esc` | 暂停 / 继续 |

触屏设备会自动显示虚拟按键。

## 玩法

- 把车**完整停进绿色车位**（四角都在车位线内），车身与车位方向偏差小于 9°；
- 停稳松开按键，保持约 1 秒（会出现绿色进度环）即可过关；
- 碰撞墙壁、立柱或其他车辆会计入碰撞次数，影响星级评价；
- 每关有目标时间：**3★** = 零碰撞且达标，**2★** = 碰撞 ≤2 次且时间不超目标 1.8 倍；
- 最佳成绩自动保存在浏览器本地（localStorage）。

## 技术要点

- **Canvas 2D** 渲染，支持高分屏（devicePixelRatio 自适应）；
- 自定义**旋转矩形碰撞**：SAT 分离轴检测 + MTV 最小平移推出，碰墙可以沿墙滑动不卡死；
- **倒车雷达**：倒车时从车尾发出 3 条射线探测最近障碍，距离越近提示音越急促，画面同步显示红/黄/绿探测线；
- **WebAudio** 合成音效（雷达提示、碰撞、过关），可一键静音；
- 帧率无关的物理步进（dt 归一），60Hz/120Hz 屏幕手感一致。
